# Logistic_Regression_classification
Binary/Multi-class classification pipeline using Logistic Regression with accuracy, precision, recall, and ROC-AUC evaluation.

# 🎯 Logistic Regression Classification Project

An end-to-end Machine Learning classification pipeline built with Python and Scikit-Learn.

---

## 🚀 Project Overview
This project applies Logistic Regression to classify target outcomes based on input features:
* Exploratory Data Analysis & Preprocessing (handling missing values, encoding, scaling)
* Model training using Scikit-Learn's `LogisticRegression`
* Evaluation using classification metrics and confusion matrix

---

## 📊 Evaluation & Metrics
* **Accuracy Score**
* **Precision / Recall / F1-Score**
* **Confusion Matrix & ROC-AUC**

---

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `seaborn`
* **Environment:** Google Colab

---
